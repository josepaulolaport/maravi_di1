## 8. Pitfalls already hit (save yourself the time)

- **RTK proxy:** the shell rewrites `npx`/`npm` output and can swallow it or change exit codes. Run checks as `rtk proxy npx vitest run`, `rtk proxy npm run -s lint`, etc.
- **MSW 3:** the option is `onUnhandledFrame`, not `onUnhandledRequest`. AI reviewers flag it; they are wrong.
- **Mantine 9 dates:** `DatePickerInput` works with `YYYY-MM-DD` **strings** (`DateStringValue`), not `Date`.
- **Vite 8:** chunking is `build.rolldownOptions` (Rolldown), not `rollupOptions`.
- **Testing Library:** `Intl` puts a no-break space after `R$`; the default normalizer turns it into a plain space, so write expectations with a plain space (`'R$ 506.059,27'`).
- **Recharts in jsdom:** charts do not draw (size 0); unit-test the data preparation (see `chartData.ts`) instead of the SVG.
- **Async date change:** after changing a date or range, data reloads; use `findBy…`, not `getBy…`.
- **Vite dev server:** after moving or renaming a module, restart it; it caches the old path.
- **Decimals:** never `parseFloat`, `Number()` or `Math.round` on money (ESLint bans the first and last). `Number()` only for chart pixel coordinates, with the text formatted from the string.
- **Permissions:** `git merge` is blocked in this setup; rebuild branches with cherry-pick instead.
